## 📌 Featured Project

### DeadlineSense — Automated Job Application & Deadline Tracking

A job-application assistant designed to help students keep track of placement and internship opportunities.

**What it does:**

* Scans Gmail for placement and internship opportunities
* Extracts company, role, eligibility and deadline information
* Matches opportunities based on student eligibility
* Automatically creates Google Calendar events
* Helps users stay updated about approaching deadlines
* Uses SQLite to maintain processed opportunities

**Built with:**
`Python` `Flask` `JavaScript` `SQLite` `BeautifulSoup` `Google APIs`
